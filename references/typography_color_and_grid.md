# 字体、色彩、网格与动效（参数级指南）

规则写成"阈值 + 检测方式"。冲突时：brief 与品牌资产 > 无障碍阈值 > 本文件数值 > 个人偏好。〔TU〕

## 1. 字体系统

### 1.1 家族与字重
- 家族 ≤2（第三个只能是用于真实代码/数据的 mono）。配对必须跨分类（衬线+无衬线、几何+人文）；两款相似的无衬线放一起是冲突不是对比。标题与正文配对时 x-height 相近。〔TU〕〔AFD〕
- 同一标题内强调：用同家族的粗体/斜体，不临时插入另一家族的一个词。〔DT〕
- 字重 2–4 档（400/500/600/700 中取）。正文 400–500；600+ 留给标题与强调。<18px 不用 Thin/Light，<24px 不用 Black。〔TU〕
- 选字测试：`Il1 O0 rn/m a/o cl/d` 在正文字号下可区分；用真实文案在 16px/14px、200% 缩放、浅色与深色下各看一次。中文加测：`永和九年，岁在癸丑。0123456789 ¥1,284.50 “引号”（括号）——破折号` 【补强】
- **收敛集政策**：Inter、Roboto、Open Sans、Lato、Montserrat、Poppins、Space Grotesk、Plus Jakarta Sans、Geist、Fraunces、Instrument Serif 在 Persuade/Experience 面**禁止作默认**；Operate/Read 面可用系统栈或其中之一，但设计说明里写出具体理由（等宽数字、平台熟悉度、零加载）。〔TS〕〔DR〕〔DT〕
- 加载：子集化；`font-display: swap`；预加载标题字与正文 Regular；用 `size-adjust / ascent-override / descent-override` 对齐回退字体度量，消除 CLS；优先可变字体。〔TU〕中文全字库 5–15MB，必须用按 `unicode-range` 切片的服务（如 Google Fonts 的 Noto Sans SC）或子集化，否则用系统字体。【补强】

### 1.2 字阶（一套模数，所有字号由正文推导）〔TU〕

| 比例 | 用途 |
|---|---|
| 1.125 | 高密度数据界面、后台 |
| 1.2 | 通用产品界面（安全默认）|
| 1.25 | 营销站、中等对比 |
| 1.333 | 大胆的落地页 |
| 1.414 | 印刷感编辑排版 |
| 1.5 / 1.618 | 标题必须压倒一切的编辑/品牌页 |
| 5–12×（最大/最小） | 海报与单件作品（MC）|

- 相邻层级比 <1.2 视为"扁平"，任意两级字号差 ≤2px 视为"不可区分"；一个页面的字号种类 ≤8（Operate ≤6）。〔AU〕
- 网页 Hero `clamp()` 上限 ≤96px（6rem）；display 字距下限 −0.04em。〔DT〕海报、幻灯片封面不受此限。
- 最小字号：主文案/标题/按钮 ≥16px；辅助说明 ≥14px；<14px 仅限徽章、时间戳等微型 UI；营销页全页无 <13px。〔TU〕〔TS〕
- 语义层级 ≠ 视觉尺寸：卡片/磁贴标题 ≤20px 且用 `<h4>` 以下；指标数字不是标题；页脚栏目标题用 `<h4>`/`<h5>`。按角色命名类（`.heading-display / .heading-section / .heading-card / .label`），不按标签名推字号。〔TU〕
- 语境上限：Dashboard/应用页标题 ≤28px，组件标题 ≤24px；电商非 Hero 的 h1/h2 ≤28px；营销页才允许 display 尺寸。〔TU〕

### 1.3 行高、行长、字距

| 角色 | 拉丁文 | 中文【补强：中文列】 |
|---|---|---|
| Display（≥28px）| 1.0–1.1；斜体含 y g j p q 时 ≥1.1 并预留 `padding-bottom` 防裁切〔TU〕〔DT〕 | 1.15–1.3（汉字撑满字面框，1.0 会上下相撞）|
| h3–h6 | 1.1–1.25 | 1.3–1.45 |
| 正文 | 1.5–1.6；衬线 +0.05〔TU〕〔AFD〕 | 1.7–1.9（≥1.7〔XP〕）|
| 高密度 UI / 表格 | 1.35–1.45 | 1.5–1.6 |
| 行长 | 45–75ch，阅读理想 60–70ch；营销页 ≤62 字符〔TU〕〔TS〕 | 28–40 字/行；长文 30–38 字（`max-width: 36em`）|
| 字距 | Display −0.01 至 −0.035em；全大写标签（若真需要）+0.05–0.15em；正文 0〔TU〕〔TS〕 | 正文 0–0.05em（常用 0.02em〔XP〕）；标题 0 或正值，**绝不负字距**〔LF〕 |

- 标题→其所属正文的间距 < 上一组→该标题的间距（标题属于下文，不属于上文）。常用值：区块 h2→内容 32–48px，卡片标题→正文 8px，正文段间距 ≈1em。不靠浏览器默认 margin，不用 `<br>` 堆空行。〔TU〕〔TS〕
- `text-wrap: balance` 用于 h1–h3，`text-wrap: pretty` 用于长文；中文环境先实测，不全局强加。标题避免孤字/孤词落在最后一行；三行标题是最显眼的破绽之一。〔DT〕〔UD〕〔VD〕
- 段落左对齐；居中只给 ≤3 行的短句；不在同一阅读流里混用左对齐与居中。〔AU〕

### 1.4 数字与数据文本
- 数据列、价格、计时器：`font-variant-numeric: tabular-nums`；可比较的数字右对齐，统一小数位与单位口径。〔UX〕〔UD〕
- 数字与单位不断行（`white-space: nowrap` 或 `&nbsp;`），绝不出现 "250 / W" 折行。〔TS〕
- 日期、数字、货币一律 `Intl.DateTimeFormat` / `Intl.NumberFormat`，不手写格式串；1284 → 1,284；负数、零、null 都有呈现方案。〔AU〕〔EK break-ui〕

## 2. 中文与中西混排【补强为主，标注处出自语料】

### 2.1 文档与字体栈
- `<html lang="zh-CN">`（繁体 `zh-TW`/`zh-HK`）。缺 `lang` 时，CJK 统一码字体可能渲染出日文字形（如"骨""直"的笔形差异）。
- **默认"西文在前、中文在后"**：拉丁字母与数字走西文字体，汉字回落到中文字体。浏览器按字符逐个找字形，前面的字体若含汉字就不会落到后面的字体；品牌字体在前时必须核查其字符覆盖。〔UD typography-cjk〕
  ```css
  :root{
    --font-sans: "Hanken Grotesk", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
    --font-serif: "Source Serif 4", "Noto Serif SC", "Songti SC", "SimSun", serif;
    --font-mono: "IBM Plex Mono", ui-monospace, "SF Mono", Menlo, monospace;
  }
  ```
- **弯引号陷阱**：西文字体里的 `“ ” ‘ ’ — …` 会以西文半宽字形出现在中文句子里。解决：中文语境统一用直角引号「」，或声明一个只覆盖这些码位的中文字体放在栈首（`unicode-range: U+2018-2019, U+201C-201D, U+2014, U+2026;`），上线前逐浏览器实测。
- 免费可商用中文字体（以官方许可为准）：思源黑体/Noto Sans SC、思源宋体/Noto Serif SC、霞鹜文楷（OFL）、阿里巴巴普惠体、HarmonyOS Sans SC、MiSans、OPPO Sans。苹方、微软雅黑是系统字体，不能打包分发。
- 中文没有斜体：禁止对中文 `font-style: italic`（浏览器伪斜体）。强调用字重、字号、颜色，或着重号 `text-emphasis: filled dot; text-emphasis-position: under right;`。
- 同字号下中文视觉更大更黑：混排时先目测汉字字面与西文 x-height 是否协调，再决定是否给西文 `size-adjust` 或调整字重。〔UD typography〕

### 2.2 标点与断行
- 中文内容用全角标点；破折号用"——"（两个 U+2014，占两字宽），**只在语法需要处**使用，不用作"标题——副标题"式装饰分隔（英文 em dash 禁令不适用于中文语法用法，但适用于装饰用法）。间隔号"·"只用于人名、书名与篇名之间，不用作元信息串的分隔符。
- 避头尾：`line-break: strict;`。标点挤压：`text-spacing-trim: normal`（渐进增强）或对标题用 `font-feature-settings: "palt"`（字体须支持，思源/Noto CJK 支持）。不要把 CSS 声明存在当成"各环境都正确"。〔UD〕
- 中西文间距：首选 `text-autospace: normal`（渐进增强）；不支持时在文案中插入半角空格，二者不可叠加；数字与汉字之间同理。
- `word-break: keep-all` 不全局使用（会阻止中文正常换行）；长 URL/标识符单独 `overflow-wrap: anywhere`。〔UD〕
- 窄栏与短文本不两端对齐；两端对齐只给 ≥25 字/行的正文，并检查字距是否被拉散。〔UD〕
- 竖排 `writing-mode: vertical-rl` 是中文的原生书写方向，可作为书籍、诗词、东方题材的唯一破格；竖排中的两位数字用 `text-combine-upright: digits 2`。拉丁文旋转 90° 作装饰仍属红线。〔DT〕

### 2.3 中文版式数值速查

| 项目 | 推荐 |
|---|---|
| 正文字号 | 屏幕 16–18px（长文 ≥16px，界面 ≥15px〔XP〕）；印刷 9–11pt |
| 正文行高 | 1.7–1.9 |
| 正文字距 | 0.02–0.05em |
| 行长 | 28–40 字 |
| 段落 | 段间距 0.8–1em；首行缩进与段间距不同时使用 |
| 标题字距 | 0 至 +0.1em（宋体展示可更疏），不负 |
| 中英文间距 | 约 0.25em |

### 2.4 中文特有的 AI 套路
- 全站微软雅黑/苹方一个字重到底，层级只靠颜色。
- "科技蓝紫渐变 + 粒子/光线 + 赋能企业数字化转型"的首屏。
- 每个中文标题上方配一行英文全大写小字（"关于我们 / ABOUT US"）。
- 书法字大标题 + 祥云纹 + 金色描边的"国潮"皮肤。
- "让 XX 更简单 / 更高效 / 更智能"式 h1；三张等宽卡片写"安全 · 高效 · 稳定"。

## 3. 色彩

### 3.1 先定角色，再给色值
最少角色：`canvas`（页面底）、`surface`（高一级表面）、`ink`（正文/标题）、`ink-muted`（次要文字）、`line`（分隔线，墨色 8–15%）、`accent`（唯一强调）、`accent-ink`（强调色上的文字）、`focus`、语义色 `success / warning / danger / info`、数据色 `data-1…n`。核心色板 4–6 个具名 hex；组件只引用语义 token，不写裸 hex。〔AFD〕〔TU〕〔LF〕

### 3.2 预算与位置
- 界面 90–95% 中性；颜色主要来自照片、产品与真实 logo。〔TS〕
- 强调色：Persuade 面除主按钮/品牌色块外 <3% 屏幕面积；Operate 面 ≤10%；只给主操作、当前选中、焦点、被讲述的那个数据。每个视图只有一个实心主按钮。〔TS〕〔DT〕
- 颜色是"音量旋钮"：最重要元素满饱和，次要元素降低饱和或提高明度，装饰元素最浅。〔TU〕
- 颜色锁：全页一个强调色；全页一种冷暖中性（不在暖灰与冷灰间摇摆）；第 7 屏不突然出现蓝色 CTA，页脚不突然出现青色徽章。〔DT〕
- 主题锁：全页一个主题；同主题内相邻区块可有明度差（如 `#0A0A0A` 与 `#151515`），但不在中途整页反色，例外仅一次刻意的整块色彩叙事切换。〔DT〕

### 3.3 对比度（实算，不目测）
- 公式：`ratio = (L1 + 0.05) / (L2 + 0.05)`，`L = 0.2126R + 0.7152G + 0.0722B`（sRGB 线性化：c ≤ 0.04045 时 c/12.92，否则 ((c+0.055)/1.055)^2.4）。`4.499:1` 判不合格。〔TU〕
- 阈值：正文 AA 4.5:1（AAA 7:1）；大字（≥24px 常规或 ≥18.66px 粗体）3:1；非文本 UI（控件边界、图标、焦点环、图表关键边界）3:1。〔TU〕
- 营销页里"人要读的字"目标 7:1；muted 色（≥4.5:1）只给标签、日期、元信息。灰色正文压在浅色带色底上，是最常见的失败。〔TS〕〔DT〕
- 浅色与深色主题分别重算；永远成对声明前景/背景；图片上的文字按最不利像素计算，必要时加实底而不是渐变遮罩。〔TU〕〔TS〕
- 彩色底上的次要文字用同色相加深，而不是灰色（灰字在彩底上像禁用态）。对比不够又不想让色块变暗时，反转为"浅彩底 + 深彩字"。〔TU〕
- 正文不用纯 `#000` / `#FFF`：深色主题用 `#E6E6E6–#F5F5F5` 字配 `#0A0A0A–#1A1A1A` 底，避免光晕。〔TU〕
- 颜色从不单独承载含义（错误、状态、类别都配图标、文字、形状或位置）。〔TU〕〔PP〕
- 命令行实算：`python3 <skill-dir>/scripts/slop_scan.py contrast "#5D6B72" "#ECF0F2"`。

### 3.4 底色（Ground）三令牌〔TS backgrounds〕
- `--g-main`：白，或明度 0.80–0.97 的低饱和色调，覆盖 ≥55% 页面高度；奶油页面上不放纯白面板。
- `--g-alt`：与主底同色相（±20°），暗 0.06–0.15，明度不低于 0.70。
- `--g-dark`：明度 ≤0.05（近黑或品牌最深色，不用炭灰、不用紫）；全页最多一个深色正文区块，且不紧贴 Hero 下方。
- 底色切换发生在区块边缘、整块进行；区块之间不画线，区块内部不插色带，不用内嵌彩色框假装换底。
- 非科技类页面一律平涂：无渐变（含硬分界双色）、颗粒、纸纹、光晕、纹样、毛玻璃。科技类页面全页最多一个效果：颗粒 4–10% 且不动、不压在文字/UI/照片上；网格点/十字只出现在一个深色技术区块，墨色 12–18%。

### 3.5 深色主题
- 高度用表面明度表达，不用阴影：`#121212`（底）→ `#1E1E1E`（卡）→ `#242424`（下拉）→ `#2C2C2C`（弹窗）；`#E6E6E6` 正文在四层上均 ≥11:1，`#A3A3A3` 次要文字 ≥5.5:1。〔AU〕【补强：实算】
- 层级对等：浅色主题里跳出来的 CTA，在深色主题里也要跳出来；品牌色不因深色而被去饱和到认不出。〔DT〕
- Operate 面默认双主题（`prefers-color-scheme` + 语义变量）；Persuade 面锁定单主题时写一句场景理由（谁、在哪、什么光线）。〔DT〕

### 3.7 数据颜色〔LF〕〔UD 06〕〔PP〕
- 先判数据关系：顺序（单色相明度梯，值越大越深）、发散（两端对比 + 中性中点，中点对应真实基准）、定类（离散色相，≤6 类，超过改用灰阶 + 直接标注或分面）。
- 明度即数据：最重要 = 最深（深色卡上反转为最亮）；多系列按重要性分配明度梯，不按出现顺序。
- 一个交付一种色彩系统；强调色只给一个主角；彩色时至少 3 个色阶，否则退回灰阶；颜色必须绑定真实维度并在副标题写明 `color = …`。
- 灰阶起点（lieflat Mono）：纸 `#F0EFEB`、墨 `#1C1C1A`（14.8:1）、阶梯 `#4A4944`（7.8）`#6A6963`（4.8）。**语料缺陷修正**：原 token 的 `#8F8E88` 在纸色上仅 2.9:1，不得用于文字或关键数据边界，只能作装饰性网格。【补强：实算】
- 色盲安全：不让红/绿单独承担正负；类别色加形状、线型或直接标注；在灰度下检查仍可区分。可参考 ColorBrewer 与 Paul Tol 方案。

## 4. 网格、间距、圆角与深度

### 4.1 间距刻度与层级〔TU〕〔TS〕
- 刻度（4pt）：`4 8 12 16 24 32 48 64 96 128`。禁止 13/17/22px 之类刻度外的值。
- 每个布局至少三档可见间距：

  | 角色 | 值 |
  |---|---|
  | 微（控件内 图标↔文字） | 4–8 |
  | 紧（组内） | 8–12 |
  | 默认（相关兄弟元素） | 16 |
  | 中（子组之间） | 24–32 |
  | 松（大组之间） | 48–64 |
  | 区块节奏 | 桌面 96–128；手机 ≥48 |

- **组内 < 组外（不可违反）**：组边缘到第一个子元素的内边距 > 子元素之间的间距；水平、垂直都适用。
- 表单：标签→自己的字段 4–8px；字段→下一个标签 16–24px。"处处 16px"是最常见的失败。
- 图标：图标↔文字 8px；纯图标按钮组内 4px；图标组↔带文字控件 16px。
- 调间距的方法：先给多，再逐步收，直到分组仍清晰；不要从最小值往上加。手机端保持层级**比例**，不等比缩小全部间距。区块上下内边距对称（或按固定的 top/bottom token）。

### 4.2 容器与网格
- 营销/电商：单一内容列 `width: min(100% - 2*var(--gutter), 1280px)`，gutter 桌面 80 / 平板 48 / 手机 24；页眉、每个区块、页脚共用同一 wrap，左右边线全页一致；背景可出血，内容不出列。只有阅读栏、表单卡、单个 FAQ 等组件在列内再收窄（`--measure: 65ch`）。〔TU〕〔TS〕
- 12 栏，gutter 24px（手机 12px）；每个块起于左线或栏起点、止于栏终点；卡片行（6+6、4+4+4、3×4）铺满整行且等高。〔TS layout-v4〕
- 分栏：选定一对比例（如 5/7 或 6/6）并在全页所有分栏复用；文字在左、视觉在右、顶部对齐，不左右交替成 Z 字。〔TS〕
- 应用界面：全宽应用壳；侧栏固定宽度适配其内容，主区流式；卡片、弹窗、表单有 `max-width`，只在屏幕不够时收缩。〔TU〕
- 粘性导航：`heroPaddingTop = navbarOuterHeight + 96px`（按每个断点实测导航高度）；`html { scroll-padding-top: ≥ navbarOuterHeight }`。落地页导航内部内容宽度 = 区块内容宽度，logo 与 CTA 落在同两条边线上。〔TU〕
- 网格选择：单栏（长文）/ 分栏（编辑、定价、营销）/ 模块（画廊、电商）/ 基线（编辑与印刷一致性）/ 层级（首页、混合组件 Dashboard）——为每个模板写明选择理由；数字产品默认"软网格"（栏对齐，不强制基线）。〔TU〕
- 断点由内容决定；必测宽度 1440、1024、768、390、320；320px 下无横向滚动（WCAG Reflow）。〔TU〕〔TS〕

### 4.3 圆角
- 全页锁定一个圆角族：sharp `4/6/8`（金融、开发者工具、瑞士）、soft `8/12/20`（默认）、round `10/16/24`（消费 App）、square `0/0/2`（到店场所、编辑出版）。混用须有书面规则（例："按钮全胶囊，卡片 16，输入框 8"）并处处遵守。〔TS system〕〔DT〕
- 与尺寸成比例：24px 高徽章 4–6；40px 按钮 6–10；48px 输入框 6–12；120px 卡片 12–20；400px 弹窗 16–24。卡片 ≥32px 禁用；胶囊（9999px）只给标签、开关、按钮。〔AU〕〔DT〕
- 嵌套公式：`innerRadius = outerRadius − padding`（24/8→16；20/8→12；16/4→12），内圆角不小于 6；绝不把父级圆角原样复制给有内边距的子元素。〔TU〕〔TS cards〕

### 4.4 阴影与高度〔AU elevation〕〔TU〕
- 阴影只表示高度，五级对应五种语义，同级同阴影：

  | 级 | 元素 | token |
  |---|---|---|
  | 0 | 页面、表格行、静止卡片 | `none`（用 1px 线或底色差）|
  | 1 | 可抓取的浮起元素 | `0 1px 2px rgba(0,0,0,.06)` |
  | 2 | 粘性页眉、悬浮按钮 | `0 4px 8px rgba(0,0,0,.08), 0 1px 3px rgba(0,0,0,.05)` |
  | 3 | 下拉、弹出层 | `0 8px 24px rgba(0,0,0,.10), 0 2px 6px rgba(0,0,0,.06)` |
  | 4 | 弹窗 | `0 16px 48px rgba(0,0,0,.12), 0 4px 12px rgba(0,0,0,.08)` |

- 落地感：blur ≈ 2 × offset-y（offset 4 → blur 8；offset 4 + blur 40 是"光晕"，不是阴影）；全局单一光源：offset-x 恒为 0，offset-y 为正。阴影色 5–15% 不透明度，可向底色色相偏移，不用纯黑。
- 一个元素只用一种边界定义：1px 线 **或** 阴影；"1px 线 + ≥16px 模糊阴影"是幽灵卡红线。〔DT〕
- 深色主题不用阴影表达高度，用表面明度（§3.5）。
- 不用阴影的深度：明度差（浅卡在灰底上即"浮起"）、重叠（头像压在卡片边缘）、尺度与清晰度。〔TU〕

## 5. 动效与微交互〔EK〕〔AFD〕〔DT〕

### 5.1 该不该动（按频率）

| 使用频率 | 决定 |
|---|---|
| 每天 100+ 次（快捷键、命令面板开关） | 不动画，永远 |
| 每天几十次（hover、列表导航） | 去掉或大幅减弱 |
| 偶尔（弹窗、抽屉、Toast） | 标准动画 |
| 罕见/首次（引导、反馈、庆祝） | 可以有惊喜 |

合法目的只有：空间连续、状态指示、解释、反馈、避免突变。键盘触发的动作不加动画。页面级：一个编排好的时刻（一次加载序列或一次揭示）胜过处处小动画；回应用户动作（展开、打开、确认）并显示"什么变了"的动效受欢迎。

### 5.2 曲线与时长
```css
:root{
  --ease-out: cubic-bezier(0.23, 1, 0.32, 1);      /* 进入/退出，默认 */
  --ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);  /* 屏内移动/形变 */
  --ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);   /* 抽屉/底部面板 */
  --dur-press: 140ms; --dur-pop: 180ms; --dur-menu: 220ms; --dur-modal: 260ms;
}
```
- 选曲线顺序：进出 → ease-out；屏内移动/形变 → ease-in-out；hover/颜色 → ease；匀速循环（进度、跑马灯）→ linear；**UI 永不 ease-in**。
- 时长：按下反馈 100–160ms；tooltip/小气泡 125–200ms；下拉/选择器 150–250ms；弹窗/抽屉 200–500ms；UI 过渡总体 <300ms；营销/解释性动效可更长。退出比进入快（如进入 260ms、退出 180ms）。
- 首个 tooltip 有延迟，之后相邻 tooltip 即时出现。

### 5.3 物理感与可打断
- 永不从 `scale(0)` 出现：从 `scale(0.95)`（0.9–0.97）+ `opacity: 0` 开始。按下：`:active { transform: scale(0.97) }`，160ms ease-out。
- 弹出层从触发点缩放（`transform-origin` 指向触发器）；模态框例外，居中。
- 会被快速重复触发的 UI（Toast、开关、拖拽）用 transition 或弹簧，不用 keyframes（keyframes 被打断会从 0 重来）。入场可用 `@starting-style`。
- 弹簧：默认临界阻尼（`bounce: 0`, `duration: 0.3–0.5s`）；只有手势本身带动量（甩、抛、拖拽释放）时才给 0.1–0.3 的回弹，并把松手速度传给弹簧。拖拽越界用阻尼而非硬墙；按下时（pointerdown）立即高亮，不等 click。〔EK apple-design〕
- 不对称时间：用户在"决定"的地方慢（长按 2s 线性），系统"回应"的地方快（松开 200ms）。
- 交叉淡入露出两层叠影时，过渡期间加 `filter: blur(2px)` 融合；blur 始终 <20px。

### 5.4 Stagger、滚动与循环
- 组内错峰 30–80ms；错峰是装饰，播放期间不阻塞交互。图表：点阵 8–15ms/个，柱 80–130ms/根，`quarticOut` 类快进快停、不回弹。〔LF〕
- 不做：每个区块滚动淡入、文字视差、scroll-jacking、平滑滚动库、二次触发的滚动动画；Hero 只在加载时入场一次。〔TS〕〔AFD〕
- 任何持续 >5 秒的自动运动提供暂停控件（WCAG 2.2.2）；跑马灯每页最多 1 条。〔TS〕〔DT〕
- SVG 流动虚线：`stroke-dashoffset` 每周期位移量 = `stroke-dasharray` 周期之和（`5 5` → `-10`），否则循环会跳；0.6–0.9s 读作"电流"，>1.5s 读作"坏了"；每张图 3–6 个流动点，只放在方向有信息量的路径上。〔DM〕

### 5.5 性能与无障碍
- 只动画 `transform` 与 `opacity`；禁止 `transition: all`；不动画 `top/left/width/height/margin/padding`。〔EK〕
- 不通过父级 CSS 变量驱动子元素 transform；Framer Motion 用完整 `transform` 字符串而非 `x/y` 简写；预设动画用 CSS/WAAPI。〔EK〕
- 全页 WebGL/3D 最多 1 处，离屏暂停；运动中的元素不加 `filter: blur()`；`backdrop-filter` ≤14px 且不覆盖大面积滚动区；`pointermove` 用 rAF 节流；被相机缩放的元素不加 `will-change`（文字会糊）。〔XP〕〔PLM〕
- `prefers-reduced-motion: reduce`：更少更柔，不是全无——保留 opacity/颜色过渡，去掉位移、缩放、视差、回弹；隐藏内容在减弱动效下必须可见。hover 位移包在 `@media (hover: hover) and (pointer: fine)` 内。焦点环出现不加动画（0ms）。〔EK〕〔TU〕〔TS〕
- Core Web Vitals 目标：LCP <2.5s、INP <200ms、CLS <0.1。〔DT〕
