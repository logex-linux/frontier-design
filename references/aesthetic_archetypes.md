# 美学原型词典（Aesthetic Archetypes）

用途：给"方向"一个可执行的语法，防止不同流派串味成平庸的折中。每个原型都写明适用/拒绝语境、字体、色盘、空间密度、形状与深度、动效、签名动作、禁忌与验收。数值未注明出处者为原型内的推荐起点，可按 brief 调整，但同一页面不跨原型混用。

## 0. 怎么选

1. **先判载体模式**（SKILL.md §3）：Operate/Read 面优先 C 精工工具或 A 瑞士网格；Persuade 面从题材出发在 A/B/D/E/H 中选；Experience 面从 B/F/G/H 中选。〔DT〕
2. **从题材的世界里找证据**：行业材料、使用场景、受众年龄与读距。"给 8–11 岁女孩的玩具"和"给金融分析师的 Dashboard"不可能是同一套审美。〔AFD〕
3. **一页一原型**：页面可按区块（导航 / 首屏 / 产品区 / 动效 / 页脚）分别找 2–3 个参考，提取的是**决策**（层级如何揭示、视觉重量如何分配），不是外观；但所有区块必须服从同一原型的字、色、形。〔DR〕
4. **一个原型只借一个签名动作作为锚点**，其余元素按该原型的"安静规则"执行。〔AFD〕
5. **原型冲突时**：brief 钉死的品牌资产 > 原型规则；原型规则 > 本人偏好。

### 原型速查

| 原型 | 一句话 | 最适合 | 坚决不用于 |
|---|---|---|---|
| A 瑞士国际主义 | 网格就是内容的秩序 | 机构、报告、信息型官网、B2B | 儿童、餐饮、情绪消费品 |
| B 编辑出版 | 读者愿意花 30 秒 | 长文、出版、文化机构、思想型品牌 | Dashboard、电商结算 |
| C 精工工具 | 工具消失在任务里 | Dashboard、开发者工具、后台、专业软件 | 品牌宣言页、活动海报 |
| D 实物官网 | 每一屏都给看真东西 | 软件/硬件/实体产品/服务的公司官网 | 纯艺术作品、展览海报 |
| E 有机安静 | 照片与留白主导，字在耳语 | 餐饮、手作、民宿、健康、慢生活品牌 | 数据密集工具、金融交易 |
| F 单/双色印刷 | 纸 + 一两种油墨 + 字与物的碰撞 | 海报、zine、文化公告、活动视觉 | 交互界面主体、长表单 |
| G 先锋平面 | 字就是建筑 | 文化海报、宣言、展览、音乐、品牌发布 | 需要高频操作的界面 |
| H 东方器物 | 一种器物、一段文脉、一张纸 | 茶、陶瓷、文博、传统工艺、中式文化品牌 | 用"国风"给任何中国品牌套皮 |

## A. 瑞士国际主义 / 几何静默（Swiss Grid / Geometric Silence）

- **适用**：信息有清晰结构、需要被信任的场景：机构、研究报告、B2B 官网、年报。〔ACD〕〔TU〕
- **字体**：一款中性 grotesk 承担全部层级（Latin 可选 Schibsted Grotesk、Host Grotesk、Hanken Grotesk、Archivo、IBM Plex Sans；商业字体如 Neue Haas Grotesk）；中文配思源黑体 / Noto Sans SC 或 HarmonyOS Sans SC。字重只用 400/500/600，层级靠尺寸与位置。〔TS〕【补强：中文配字】
- **字阶**：1.25–1.333；display 行高 1.0–1.05，字距 −0.02 至 −0.035em（中文标题 0）。
- **色盘**：白或冷灰纸 + 近黑墨 + 一个原色强调（钴蓝 `#1A4BE0` / 信号红 `#D92B21`）。实算：`#111111` on `#FFFFFF` = 18.9:1；`#1A4BE0` on `#FFFFFF` = 6.7:1。〔TS palettes〕
- **空间**：12 栏、24px gutter；所有块起止于栏线；左对齐、参差右边（ragged right）；大面积留白以"栏"为单位分配，而非随意居中。〔TS layout-v4〕
- **形状与深度**：圆角 0–4px（sharp 族 4/6/8）；无阴影；分隔只用间距或整块底色变化。
- **动效**：几乎为零；只保留交互反馈（150–200ms ease-out）。
- **签名动作**（选一）：超大数字/单词贴网格左线；不对称的 5/7 分栏；整段按基线网格对齐的信息排版。
- **禁忌（串味信号）**：圆角大卡、柔和渐变、手写体、居中排版、装饰十字线/网格线（网格要被"感觉到"，不画出来）。〔DT〕
- **验收**：在截图上叠 12 栏参考线，所有文字块左缘落在栏线上；不同左缘数 ≤3。

## B. 编辑出版（Editorial / Magazine）

- **适用**：长文、出版、文化机构、思想领导力内容；读者会停留 30 秒以上。
- **字体**：衬线只在这里是默认：标题衬线（Newsreader、Source Serif 4、EB Garamond、Literata、Besley；商业 Tiempos Headline、GT Sectra、PP Editorial New）+ 正文衬线或 grotesk；中文标题思源宋体 / Noto Serif SC，正文宋体或黑体按读距决定（屏幕长文正文优先黑体，16px 以上可用宋体）。**禁止把 Fraunces / Instrument Serif 当默认**；连续两个项目不用同一款衬线。〔DT〕〔TS type〕【补强：中文宋/黑分工】
- **字阶**：1.414 或 1.618，让头条压倒一切；正文 17–20px，行高 1.6–1.7（衬线比无衬线多 0.05–0.1），行长 60–72ch；中文正文 30–38 字/行。〔AFD〕〔TU〕
- **色盘**：纸色 + 墨色 + 极少量强调（多为文字链接或一个栏目色）。纸色可以偏暖，但不得与黄铜/赤陶强调 + 咖啡黑墨组成禁区三件套（见 SKILL.md §2）；例：亚麻纸 `#F3F1EC` + 墨 `#1D2530` + 港蓝 `#2C5877`（6.7:1）。〔TS palettes〕
- **空间**：主文单栏 + 边注栏（sidenote）；图片跨栏出血但两侧对称；段间距 ≈ 1em。
- **形状与深度**：0 圆角；发丝线（墨色 10–15%）**只**用于分隔真实的栏目层级，不铺满。
- **动效**：无入场动画；链接下划线 hover 绘制即可。
- **签名动作**（选一）：首字下沉或超大引文；跨栏大图 + 精确对齐的图注（图注说明事实，不写装饰性摄影署名）；目录式开篇。
- **禁忌**：给每段配卡片；在 Dashboard 用衬线标签；"报纸风"发丝线 + 零圆角 + 密集多栏被当作万能皮肤（它是 AI 五大默认之一）。〔AFD〕
- **验收**：正文段落行长落在 60–72ch（中文 30–38 字）；页面去掉所有图片后仍是一篇排版完整的文章。

## C. 精工工具（Precision Instrument）

- **适用**：Dashboard、开发者工具、运维台、专业软件、设置页、表单——用户一天打开几十次。
- **字体**：单一家族撑全场，必须有等宽数字（`font-variant-numeric: tabular-nums`）：IBM Plex Sans + Plex Mono、Chivo + Chivo Mono、Manrope（数字开阔）、SUSE；系统栈也合格（Operate 面可以选择熟悉与零加载）。Mono 只给代码、ID、命令、URL。中文用系统栈 `"PingFang SC", "Microsoft YaHei"` 或 HarmonyOS Sans SC。〔DT pre-flight〕〔DD〕〔TS type〕
- **字阶**：1.125–1.2，固定 rem，不用流式 `clamp()`；页面标题 ≤28px，组件/卡片标题 ≤24px，正文与表格 14–16px，标签 ≥13px。〔TU〕〔DT〕
- **色盘**：低饱和中性两层（画布 + 侧栏/工具栏第二层）+ 一个强调色（≤10% 面积，只给主操作、选中、焦点）+ 语义色（成功/警告/危险/信息，均配图标或文字）。浅色可选 `#EEF0F3 / #E2E5EA / #0B0C0E / #5D6470 / #1F2DE6`；深色以明度表达高度：`#121212 → #1E1E1E → #242424 → #2C2C2C`，正文 `#E6E6E6`（在最亮层 `#2C2C2C` 上仍 ≥11:1）。〔TS palettes〕〔AU〕
- **空间**：全宽应用壳（不是 1280 营销列）；侧栏固定宽、主区流式；密度高但三档间距仍可辨（4/8、12/16、24/32）。
- **形状与深度**：圆角 4–8px（sharp 族）；阴影只给浮层（下拉、弹窗），卡片用 1px 线或底色差，二选一。
- **动效**：150–250ms；只表达状态；频率 >100 次/天的操作（快捷键、命令面板）零动画。〔EK〕
- **浮层材质（可选，仅此原型）**：工具栏/侧栏作为**浮在滚动内容之上**的层时，可用 `backdrop-filter: blur(≤14px)` + 半透明底；卡片与正文区域永不毛玻璃；`prefers-reduced-transparency` 时回退为不透明底。〔EK apple-design〕〔XP〕
- **签名动作**（选一）：一条极精确的数据密度节奏（对齐的数列 + 右对齐数字）；一个完美的命令面板；状态色只出现在真正的异常上。
- **禁忌**：营销 Hero 字号、渐变 KPI 卡、图标装在彩色圆里、展示字体做标签、自造滚动条与非标控件。〔DT〕
- **验收**：同一个"保存"在所有屏幕外观一致；关掉颜色（灰度截图）后状态仍可区分。

## D. 实物官网（One-screen Corporate，以 figma.com 与 x.ai 为水位线）

- **适用**：公司与产品官网：软件、硬件、实体产品、服务。标准是"一家好公司会发布的网站"：直说卖什么、每屏都给看真东西、看起来是为这个客户做的。〔TS〕
- **先判业务类型，它决定一切**〔TS〕：

  | 类型 | 主角 | 允许 | 不允许 |
  |---|---|---|---|
  | 软件 / AI / 开发者工具 | 真实产品界面（以 HTML 实现的真实片段，展示它处理的对象，如代码评审工具展示红绿 diff + Accept） | 一个效果层、0–2 张"脉冲"示意图、深色 Hero | 通用 Dashboard 冒充产品 |
  | 硬件 / 科技设备 | 产品照片（或同类替身照片，报告中列明） | 一个效果层 | 手绘 SVG 代替产品 |
  | 实体产品 / 消费品牌 | 产品大图，每屏 ≥2 张照片 | 一个品牌色整块区 | 着色器、颗粒、渐变 |
  | 服务（诊所、律所、工作室） | 人、空间、作品 | 平涂底色 | 任何特效 |
  | 到店场所（咖啡、面包、民宿、商店） | 场所照片 12–20 张 | 平涂底色、方形照片 | 特效、循环动画、深色页面 |

- **字体**：一个家族，或 display + text 各司其职；字重 400/500（导航标志首字母可 600，**不用 700/800**）；20px 以下不用细体。避开收敛集（Inter、Roboto、Open Sans、Lato、Montserrat、Poppins、Space Grotesk、Plus Jakarta Sans）。可选：Mona Sans（硬件/平台）、Schibsted Grotesk（媒体/机构）、Onest、Funnel Display + Funnel Sans（消费 App）、Bricolage Grotesque（有性格的消费品）、Red Hat Display/Text（金融顾问、教育）。〔TS layout-v4〕〔TS type〕
- **字号（1440 / 390）**：h1 72/38、h2 48/30、h3 与引文 28/24、导语与卡片标题 20/18、正文 16、小字 14、标签 13/500 句首大写；相邻层级 ≥1.3×（1024 以下 ≥1.2×）；全页无 <13px；行长 ≤62 字符。〔TS layout-v4〕
- **色盘**：界面 90–95% 中性，颜色来自照片、产品与真实 logo；一个强调色只给主按钮（全视图唯一的实心按钮）、焦点环、链接、少量状态，其他位置 <3% 屏幕面积；"品牌色整块区"上的每个字 ≥7:1。〔TS system〕
- **空间**：一个 `.wrap`：`width: min(100% - 2*gutter, 1280px)`，gutter 80/24；首屏只有 Hero；每个区块恰好 1 或 2 屏高（1440×900 下内容高 495–708px 为一屏）；区块之间只用整块底色切换或留白分隔，不画分割线。〔TS layout-v4〕
- **形状与深度**：圆角族三选一并全页锁定：sharp 4/6/8（金融、开发者工具）、soft 8/12/20（默认）、round 10/16/24（消费 App），到店场所方角。卡片"几乎不存在"：比页面高一级的底色 + 墨色 8–14% 的 1px 线 + 32/28/24px 内边距，静止时无模糊阴影。〔TS cards〕
- **动效**：Hero 加载时入场一次；全页 1–2 个"时刻"；可点击的卡片 hover 上浮 2px、照片框内放大 1.02–1.03；不可点击的东西不动；任何超过 5 秒的循环带暂停按钮。〔TS〕
- **签名动作**（选一，按素材发牌而非凭喜好）：产品整体大图占内容宽 80% 以上；超大一句陈述；一个真实产品窗口被画框边缘裁切（暗示更大的整体）。
- **禁忌**：图片下的说明文字、紫色、滚动淡入、视差、轮播、虚构证言与数字、同一张图出现两次、导航毛玻璃/缩放/变色。〔TS〕
- **验收**：每个 `scrollY = k × 视口高` 的截图里恰好一个区块；左右内容边线全页一致。

## E. 有机安静（Analog Meditation / Organic Calm）

- **适用**：餐饮、手作、民宿、健康、慢生活、自然题材。照片与插画主导，字体"耳语"。〔ACD〕
- **字体**：一款温和的人文/几何 sans（Figtree、Albert Sans、Rethink Sans、Hanken Grotesk）；只有当题材真的属于出版/传统时才用衬线（Newsreader、Lora、Literata），并写出理由。中文正文思源黑体，标题可用思源宋体细一档（Light/Regular，≥24px）。〔DT〕〔TS type〕
- **色盘**：从题材材料取：泥土、植物、石材、织物。**避开**"暖奶油底 + 黄铜/赤陶/牛血红强调 + 咖啡黑墨"三件套（DT 列出的默认 hex 族：底 `#F5F1EA #F7F5F1 #FBF8F1 #EFEAE0 #ECE6DB #FAF7F1 #E8DFCB`，强调 `#B08947 #B6553A #9A2436 #9C6E2A #BC7C3A #7D5621`，墨 `#1A1714 #1A1814 #1B1814`）。暖纸底本身可用，但强调色与墨色必须换族。可选替代：粘土+松绿 `#EFE9E0 / #22261F / #2E5B44`（强调 on 底 6.5:1）、橄榄+骨白 `#ECEBE7 / #38450F`（8.7:1）、沙与苔 `#DDD6C6 / #2A2A26 / #4F6238`（墨 10.0:1，苔绿 4.6:1）。连续两个同类项目不得用同一色族。〔DT core-rules〕〔TS palettes〕
- **空间**：大面积负空间是主角的呼吸；照片按栏跨度排布，一行一个比例（4:5、4:3、3:2、1:1）；文字块窄（≤55ch / ≤30 字）。
- **形状与深度**：方角或 2–4px；全部平涂，无渐变、颗粒、纸纹、毛玻璃、阴影（非科技类页面一律平涂）。〔TS backgrounds〕
- **动效**：照片 hover 放大 1.02；无其他。
- **签名动作**（选一）：一张满版照片无任何叠字；把地址或店名设为超大字作为唯一的"字体时刻"。
- **禁忌**：手绘 SVG 植物、`feTurbulence` 假纸纹、做旧效果、水彩晕染背景。〔DT〕
- **验收**：灰度截图中照片承担 ≥50% 视觉重量；全页只有一个按钮样式。

## F. 单/双色编辑印刷（Mono-ink Editorial Print / Risograph / Duotone）

- **公式**：中性承印物 + 1–2 种油墨 + 机械复制的图像 + 字体张力 + 简短的人声。〔MC〕
- **适用**：海报、zine、文化公告、活动视觉、社交图。
- **承印物**：中性白 `#FAFAF7`（默认）、冷灰 `#E9E9E5`（建筑、科技、炭黑系）、浅米 `#F5F1E8`（食物、旅行、私人、怀旧）。半调网点 ≠ 复古：未要求复古时，不加做旧、泛黄、破边、污渍。纸面必须露出来，禁止把整页染成一层数字单色。〔MC〕
- **油墨**：每块版有明确内容角色；主版 70–85%、副版 15–30%（如日期、注释、被选中的物体）。成熟配对：钴蓝+赤陶 `#2148B8 + #C65F38`（默认）、粉蓝+信号红 `#9EB8D3 + #C83232`、植物绿+牛血红 `#008A4B + #8F3434`、炭黑+信号红 `#30343A + #C83232`、电光蓝+碳黑 `#173AE3 + #242321`、群青+安全橙 `#263E99 + #E55D2B`。单墨：钴蓝 `#2148B8`、植物绿 `#008A4B`、信号红 `#C83232`、炭黑 `#30343A`。套印重叠产生的深色不算第三种墨。〔MC〕
- **墨与小字的对比**（实算，【补强】）：钴蓝 `#2148B8` on `#FAFAF7` = 7.5:1，可排小字；信号红 `#C83232` = 5.1:1；赤陶 `#C65F38` = 3.9:1，只能用于 ≥24px 的字或图形，日期等小字改由主版承担。
- **构图四步**〔MC〕：①一个物体主导（占画面 45–80%，至少一边被裁切）；②字与物碰撞（标题穿过、覆盖、绕开或紧贴主体）；③纸穿过图像（高光剪掉露纸、网点淡出、版间镂空）；④一个手工动作打断系统（圈注、手绘线、套准标记、旋转标签、刻度条，只选一种）。
- **空间**：空白纸 25–55%（默认 35%）；外边距为页宽 5–9%；对齐一条隐形左线或 2–3 栏；一个焦点事件 + 一个释放区；永不全部居中、永不平均分布。〔MC〕
- **字体**：一个主展示声部 + 一个功能声部，手写只能作为一句插话；最大字 / 最小字 = 5–12×（字即主体时 12–20×）；展示文案 2–8 个词。字型角色按内容选：文学衬线（安静、私人）、宽 grotesk（音乐、青年文化）、压缩 grotesk（公共活动）、程序化（日期与事实主导，等宽数字）、旋转标题（大胆封面，仅一处旋转）。〔MC typography.json〕
- **瑕疵预算**：当代作品 0–2 个（轻微墨量不均、1–2mm 套准偏移），复古/触感作品 2–3 个；只作用于大字、图版、实色块，**绝不**扭曲小字与事实信息。〔MC〕
- **禁忌**：渐变字、描边字、投影字、充气 3D 字、"奢侈时尚"式的大字距；安全的"左标题右整图"二分；多种涂鸦风格叠成剪贴簿。〔MC〕
- **验收**：缩略图中焦点事件一眼可辨、释放区明显更安静；数色版：除纸色外 ≤2 种墨。

## G. 先锋平面（Concrete Poetry / Monumental Type）

- **适用**：文化海报、宣言、展览、音乐、品牌发布的主视觉——字就是建筑。〔ACD〕
- **字体**：宽体或压缩体 grotesk 的极端字重/字宽（Anybody、Archivo 宽轴、Mona Sans 宽轴；中文思源黑体 Heavy、阿里巴巴普惠体 Heavy），单词级巨字 + 极小标签，二者比例 ≥12:1。授权以字体官方许可为准。〔ACD〕〔TS type〕【补强：中文字体】
- **色盘**：大色块 + 一种对撞色；可整版满底（钴蓝场 `#0034EB` 配白字 = 7.8:1）。色块之间以明度差区分，不只以色相区分。〔TS palettes〕〔VD〕
- **空间**：粗野主义式的空间切分；元素允许出血、被裁切，但**没有任何东西意外掉出画布或互相压住**——每次重叠都是设计过的。〔ACD〕
- **形状与深度**：零圆角、零阴影；深度只来自尺度与重叠。
- **动效**（若是数字海报/动态版）：一次巨字遮罩揭示（clip-path），之后静止。
- **签名动作**：一个单词占满画面宽度；字被物体切断仍可推断。
- **禁忌**：渐变、发光、"设计感"装饰十字线、竖排的拉丁旋转文字作装饰（中文竖排是书写方向，不在此禁）。〔DT〕
- **验收**：画面中文字数 ≤ 12 个词（或 ≤ 20 个汉字）的主信息；缩到邮票大小仍能读出主词。

## H. 东方器物（Eastern Material / 器物与文脉）【补强：原型结构；色值出自用户 design/ 色彩 SOP】

- **适用**：茶、陶瓷、文博、非遗工艺、中式文化品牌、东方题材的编辑物。**不适用**：把"国风"当皮肤套给任何中国品牌。〔UD color-sop〕
- **先选一个具体文化素材，再决定颜色**（青绿山水、宫墙琉璃、漆器、园林、某一窑口的釉色），每组 3–6 色，指定主色/底色/点缀；不把不同朝代、地域、工艺拼成泛化"中式色板"。色值是屏幕近似，不称"标准文物色"。〔UD〕
- **可直接撑起正文对比的素材色板**（已实算）：龙泉青釉 `#DCD9C8` 底 + `#2E4740` 墨（7.1:1）；青花浓蓝 `#F3F0E7` + `#173E73`（9.3:1）；定窑象牙白 `#F1EADB` + `#4B453D`（7.9:1）；宋画绢色 `#E9DFC8` + `#3E5552`（6.0:1）；江南黛青 `#EFE9DB` + `#344D53`（7.4:1）；漆器朱黑 `#E8DCC5` + `#3B2925`（10.1:1，朱 `#A52E2B` 作强调 5.1:1）；墨分五色 `#F3EFE5` + `#171A19`（15.3:1）。
- **需要外加墨色才能排正文的色板**：汝窑天青（组内最大对比 3.0:1）、永乐甜白（3.0:1）、郎窑红（4.2:1）——作大面积表面或插画色，文字用墨分五色的 `#171A19` / `#383B39`。〔UD 实算〕
- **字体**：标题思源宋体 / Noto Serif SC（展示尺寸可加字距 +0.05–0.1em 制造疏朗）；正文思源黑体或宋体按读距选；霞鹜文楷只用于文人笔记、诗词类内容；书法字体只做 logo 或单字印章级元素，绝不做正文或长标题。中文无斜体，强调用字重或着重号。【补强】
- **空间**：大留白 + 竖排（`writing-mode: vertical-rl`）作为唯一的"破格"；对齐一条纵轴；器物照片单件居中或按栏偏置。
- **形状与深度**：方角；平涂；印章红只在所选素材本身含有时使用，且全页最多一处。
- **动效**：几乎为零；可有一次墨色由淡到浓的显影（opacity + 轻微 blur ≤4px，600–900ms，仅首屏一次）。
- **禁忌（中文 AI 套路）**：大红大金"国潮"、祥云/回纹/水墨晕染铺底、书法大标题 + 金色描边、龙凤剪影、渐变红灯笼；中英双语装饰小标题。【补强】
- **验收**：能说出色板来自哪一件器物或哪一种工艺；去掉所有纹样后，版面仍成立。
